# AI Text Summarization

AI-powered text summarization web application built with Python, Flask and Google Gemini.

## Features

- AI-powered text summarization
- Bring Your Own Gemini API Key
- Short Summary mode
- Detailed Summary mode
- Bullet Notes mode
- Exam Notes mode
- Word statistics
- Sentence statistics
- Reduction percentage
- Copy summary
- Download summary as TXT
- Download summary as PDF
- Responsive dark futuristic UI
- Hindi and multilingual text support
- No user account required

## Technology

- Python
- Flask
- Google GenAI Python SDK
- Gemini AI
- ReportLab
- HTML
- CSS
- JavaScript
